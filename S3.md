# S3
Amazon S3 (Simple Storage Service) is AWS’s object storage service used to store any amount of data securely, durably, and at massive scale.

# What is S3 in Simple Words?
Think of S3 like:
Google Drive
Dropbox
Hard disk in the cloud
But built for applications and infrastructure, not just people.

You store:
Images,Videos,Logs,Backups,Static websites,Application assets,Database backups,ML datasets,Any file


Core S3 Concepts
S3 has only two main things:
Everything revolves around these.
S3
 └── Bucket
      └── Objects (files)

# What is a Bucket?
A bucket is a container that holds files.
Example:
Bucket: my-app-data
# Inside the bucket:
my-app-data
 ├── images/
 ├── backups/
 └── logs/

# Important Bucket Rules
Bucket name must be globally unique
No two users can have same bucket name.


# Bucket Properties
A bucket has:
Region (where stored)
Permissions,Versioning,Encryption,Storage class,Lifecycle rules

# What is an Object?
An object is simply a file stored in S3.

# Object Structure
Each object has:
Object = Data + Metadata + Key
1) Data
Actual file content.

2) Metadata
Information about file:
Size,Type,Last modified,Encryption,Owner

3) Key
Unique path inside bucket.
ex : images/user1/photo.png

# S3 Folder Reality (Important Concept)
S3 does NOT really have folders.
Folders are just part of object key.

Example:
images/photo.png
Actually stored as:
Key = images/photo.png
So folders are just UI illusion.

# S3 Storage Classes
Storage class decides:
Cost
Availability
Retrieval speed
Different data needs different storage.

# Storage Classes Overview
1) S3 Standard (Default)

Used for:
Websites
Apps
frequently accessed data
Features:
Low latency
High throughput
Multi-AZ storage


2) S3 Intelligent-Tiering
Automatically moves data between tiers based on usage.
Good when:
Access pattern unknown
AWS shifts data automatically.

3) S3 Standard-Infrequent Access (Standard-IA)
For data accessed rarely.
Example:
Old reports
Backups
Cheaper storage, but retrieval costs money.

4) S3 One Zone-IA
Stored in one availability zone only.
Cheaper but less safe.
Used for:
Re-creatable data
Temporary backups

5) S3 Glacier Instant Retrieval
Archive data but fast access.
Use cases:
Medical images
Media archives

5) S3 Glacier Deep Archive
Cheapest storage.
Access time:
Hours
Used for:
Compliance data
Old backups
Long-term archive

7) S3 Durability & Availability
Durability
S3 durability = 99.999999999% (11 nines)
Meaning:
Data almost never lost.
Availability
Standard storage = 99.99% availability
Meaning:
Service accessible almost always.

8) S3 Security
Security options:
Bucket Policies
Rules controlling access.

Example:
Allow public read
Deny delete
IAM Policies
User permissions.

Example:
Allow user to upload objects
Encryption Options
Server-side encryption
AWS encrypts data.
Client-side encryption
You encrypt before upload.


9) Versioning in S3
S3 can store file versions.

Example:
Upload:
report.pdf v1
report.pdf v2
report.pdf v3

Old versions kept.
Useful for:
Restore deleted files
Rollback changes

10) Lifecycle Policies
Automatically move or delete files.

Example:
After 30 days → move to IA
After 90 days → move to Glacier
After 1 year → delete
Saves cost automatically.

11) S3 Common Real-World Uses
Static Website Hosting
Host HTML, CSS, JS.
Backup Storage
DB backups, logs.
App Assets
Images, videos, downloads.
DevOps Artifacts
Docker images, build files.

# S3 Bucket = Container
A bucket is a container that holds objects.
Top-level storage unit in S3
You create buckets first
Buckets store objects (files)
Bucket names must be globally unique
Buckets are created in a region

# S3 Object = Actual File
An object is the actual file stored inside a bucket.
An object includes:
File data
Metadata
Unique key (path)
